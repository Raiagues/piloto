# UI polish revision

This revision preserves the established aerospace blueprint visual language while addressing interaction and viewport issues reported during desktop and mobile testing.

Changes

- replace generated SVG satellite drawings on the home screen with the approved 2D technical-view image set
- rotate through five technical satellite views
- stabilize card dragging with native pointer capture and commit positions back into the persistent project model
- keep the study setup action bar visible so the conception room can always be entered
- fit the study setup and conception workspace inside desktop monitor heights
- improve narrow-screen and mobile layouts
- keep canvas interactions from selecting text
- keep drawers, sidebars and action controls reachable on touch devices

The existing project model, inconsistency study drafts, scoped progress, project export and bilingual interface remain unchanged.
